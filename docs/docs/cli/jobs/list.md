## Overview

Learn how to list Husonym jobs with the husonym jobs list command.

The `husonym jobs list` command is used to list the currently configured Husonym jobs for a specific account.

## Usage

```bash
husonym jobs list
```

### Aliases

```bash
husonym jobs ls
```
