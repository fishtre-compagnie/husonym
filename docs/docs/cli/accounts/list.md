# husonym list

## Overview

Learn how to list Husonym accounts with the husonym accounts list command.

The `husonym accounts list` command is used to list the personal and team accounts for a user or api key.

## Usage

```bash
husonym accounts list
```

### Aliases

```bash
husonym accounts ls
```
